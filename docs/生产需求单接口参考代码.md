# 生产需求单接口参考代码

本文档用于替换 `ToothbrushProductionJob` 中“牙刷、塑料、木头”等硬编码逻辑。目标是把生产需求保存到数据表，再由通用生产任务执行。

## 表职责

现有表职责：

- `warehouse`：仓库基础信息，例如地址、联系人、状态。
- `warehouse_stock`：仓库库存余额，表示某个仓库里的某个商品当前有多少库存。

生产需求单建议拆成两张表：

- `production_order`：生产什么、生产多少、成品入哪个仓库。
- `production_order_material`：这张生产单需要哪些原料、每种原料需要多少。

生产单只需要保存 `warehouse_id`，不要保存 `warehouse_stock_id`。库存记录应该由库存服务根据 `warehouse_id + product_id` 查询或自动创建。

## 状态约定

参考你现有 `MaterialStockAllocationService` 的写法，生产单状态建议先用 `Integer`：

```text
production_order.status:
0 待处理
1 处理中
2 已完成
3 失败

production_order_material.status:
0 待处理
1 已锁定
2 已出库
3 已释放
```

## 建议接口

```http
POST /api/v1/production-order/create
```

请求体：

```json
{
  "productId": 1,
  "productQuantity": 100,
  "warehouseId": 1,
  "materials": [
    {
      "materialId": 2,
      "quantity": 10
    },
    {
      "materialId": 3,
      "quantity": 10
    }
  ]
}
```

## 执行流程

```text
创建 production_order
        ↓
保存 production_order_material 明细
        ↓
定时任务扫描状态为 0 的生产单
        ↓
根据明细创建原料备料单
        ↓
锁定原料
        ↓
原料自动出库
        ↓
成品入库 warehouse_id + product_id
        ↓
生产单状态改为 2
```

```java
package cn.bugstack.trigger.http;

import cn.bugstack.api.request.production.ProductionOrderCreateRequest;
import cn.bugstack.api.response.Response;
import cn.bugstack.domain.production.model.vo.ProductionOrderMaterialVO;
import cn.bugstack.domain.production.service.IProductionOrderService;
import cn.bugstack.types.enums.ResponseCode;
import lombok.extern.slf4j.Slf4j;
import org.springframework.validation.annotation.Validated;
import org.springframework.web.bind.annotation.*;

import javax.annotation.Resource;
import javax.validation.Valid;
import java.util.List;
import java.util.stream.Collectors;

@Slf4j
@RestController
@CrossOrigin("*")
@Validated
@RequestMapping("/api/v1/production-order")
public class ProductionOrderController {

    @Resource
    private IProductionOrderService productionOrderService;

    @PostMapping("create")
    public Response<Long> create(@Valid @RequestBody ProductionOrderCreateRequest request) {
        log.info("创建生产需求单开始 request:{}", request);

        List<ProductionOrderMaterialVO> materials = request.getMaterials().stream()
                .map(item -> ProductionOrderMaterialVO.builder()
                        .materialId(item.getMaterialId())
                        .materialQuantity(item.getQuantity())
                        .status(0)
                        .isDel(0)
                        .build())
                .collect(Collectors.toList());

        Long orderId = productionOrderService.createOrder(
                request.getProductId(),
                request.getProductQuantity(),
                request.getWarehouseId(),
                materials
        );

        log.info("创建生产需求单完成 orderId:{}", orderId);
        return Response.<Long>builder()
                .code(ResponseCode.SUCCESS.getCode())
                .info(ResponseCode.SUCCESS.getInfo())
                .data(orderId)
                .build();
    }
}
```

```java
package cn.bugstack.domain.production.service;

import cn.bugstack.domain.materialstockallocation.service.IMaterialStockAllocationService;
import cn.bugstack.domain.production.model.aggregate.ProductionOrderAggregate;
import cn.bugstack.domain.production.model.vo.ProductionOrderMaterialVO;
import cn.bugstack.domain.production.repository.IProductionOrderRepository;
import cn.bugstack.domain.warehousestock.service.IStockService;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import javax.annotation.Resource;
import java.time.LocalDateTime;
import java.util.ArrayList;
import java.util.List;
import java.util.UUID;

@Slf4j
@Service
public class ProductionOrderService implements IProductionOrderService {

    @Resource
    private IProductionOrderRepository productionOrderRepository;

    @Resource
    private IMaterialStockAllocationService materialStockAllocationService;

    @Resource
    private IStockService stockService;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public Long createOrder(Long productId, Integer productQuantity, Long warehouseId, List<ProductionOrderMaterialVO> materials) {
        if (productId == null) throw new IllegalArgumentException("生产商品ID不能为空");
        if (productQuantity == null || productQuantity <= 0) throw new IllegalArgumentException("生产数量必须大于0");
        if (warehouseId == null) throw new IllegalArgumentException("入库仓库ID不能为空");
        if (materials == null || materials.isEmpty()) throw new IllegalArgumentException("生产原料不能为空");

        LocalDateTime now = LocalDateTime.now();
        ProductionOrderAggregate order = ProductionOrderAggregate.builder()
                .orderNo("PO" + UUID.randomUUID().toString().replace("-", ""))
                .productId(productId)
                .productQuantity(productQuantity)
                .warehouseId(warehouseId)
                .status(0)
                .isDel(0)
                .createTime(now)
                .updateTime(now)
                .build();

        Long orderId = productionOrderRepository.saveOrder(order);
        for (ProductionOrderMaterialVO material : materials) {
            material.setProductionOrderId(orderId);
            material.setStatus(0);
            material.setIsDel(0);
            material.setCreateTime(now);
            material.setUpdateTime(now);
        }
        productionOrderRepository.saveOrderMaterials(orderId, materials);
        return orderId;
    }

    @Override
    public void executeCreatedOrders() {
        List<ProductionOrderAggregate> orders = productionOrderRepository.queryCreatedOrders(10);
        for (ProductionOrderAggregate order : orders) {
            executeOne(order);
        }
    }

    @Transactional(rollbackFor = Exception.class)
    public void executeOne(ProductionOrderAggregate order) {
        productionOrderRepository.updateOrderStatus(order.getId(), 1);

        List<String> lockedAllocationNos = new ArrayList<>();
        try {
            List<ProductionOrderMaterialVO> materials = productionOrderRepository.queryMaterialsByOrderId(order.getId());

            for (ProductionOrderMaterialVO material : materials) {
                String allocationNo = materialStockAllocationService.create(
                        material.getMaterialId(),
                        material.getMaterialQuantity(),
                        "生产单" + order.getOrderNo() + "备料"
                );
                materialStockAllocationService.lock(allocationNo);
                lockedAllocationNos.add(allocationNo);

                productionOrderRepository.updateMaterialAllocationNo(material.getId(), allocationNo, 1);
            }

            for (String allocationNo : lockedAllocationNos) {
                materialStockAllocationService.autoOutbound(allocationNo);
            }

            stockService.inbound(order.getWarehouseId(), order.getProductId(), order.getProductQuantity());
            productionOrderRepository.updateOrderStatus(order.getId(), 2);
        } catch (Exception e) {
            for (String allocationNo : lockedAllocationNos) {
                try {
                    materialStockAllocationService.release(allocationNo);
                } catch (Exception releaseException) {
                    log.error("生产单释放原料失败 allocationNo:{}", allocationNo, releaseException);
                }
            }
            productionOrderRepository.updateOrderStatus(order.getId(), 3);
            throw e;
        }
    }
}
```

```java
package cn.bugstack.trigger.job;

import cn.bugstack.domain.production.service.IProductionOrderService;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;

import javax.annotation.Resource;
import java.util.concurrent.atomic.AtomicBoolean;

@Slf4j
@Component
public class ProductionOrderJob {

    @Value("${production.order.job.enabled:false}")
    private boolean enabled;

    private final AtomicBoolean running = new AtomicBoolean(false);

    @Resource
    private IProductionOrderService productionOrderService;

    @Scheduled(cron = "${production.order.job.cron:0 0/1 * * * ?}")
    public void exec() {
        if (!enabled) return;
        if (!running.compareAndSet(false, true)) return;

        try {
            productionOrderService.executeCreatedOrders();
        } finally {
            running.set(false);
        }
    }
}
```

## 实现顺序建议

1. 先实现 `ProductionOrderCreateRequest` 和 `ProductionOrderController`。
2. 实现 `ProductionOrderAggregate`、`ProductionOrderMaterialVO`、`IProductionOrderService`。
3. 实现 Repository、DAO、MyBatis XML，确保生产单和明细能正常落库。
4. 用 Postman 或前端调用创建接口，确认数据写入正确。
5. 再实现 `ProductionOrderJob`，把原来的 `ToothbrushProductionJob` 改造成通用生产任务。

## 注意点

- `warehouse_id` 是业务输入，表示成品入哪个仓库。
- `warehouse_stock.id` 是库存系统内部记录，不建议放在生产需求单里。
- `production_order_material.id` 和 `material_id` 不同，更新原料明细状态时要用 `production_order_material.id`。
- 第一阶段可以只做“创建生产需求单接口”，先不自动执行生产。
- 后续如果原料需求是固定配方，可以再新增 BOM 表，由系统根据 `product_id + product_quantity` 自动生成 `production_order_material`。
