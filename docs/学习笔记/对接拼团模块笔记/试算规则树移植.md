# 试算规则树移植

## 移植目标

把参考项目 `group-buy-market` 的拼团试算规则树按抽象工厂 + 规则树的方式移植到 CC。

核心链路：

```text
GroupBuyTrialService
  -> DefaultActivityStrategyFactory.strategyHandler()
  -> RootNode
  -> SwitchNode
  -> MarketNode
  -> TagNode
  -> EndNode / ErrorNode
```

CC 侧差异：

- 商品使用 CC 的 `product`，不引入参考项目的 `sku`
- 不需要 `source + channel + goodsId` 反查活动，活动表已经保存 `productId`
- 试算请求只保留 `userId`、`activityId`、`productId`
- 活动、折扣、商品查询使用 CC 现有 repository
