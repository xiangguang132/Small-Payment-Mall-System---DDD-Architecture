## 当前已知缺口

1. 拼团活动和折扣目前只有“查”，没有“增、改、删”。
2. 当前数据库没有拼团活动/折扣数据，试算链路实际运行时会在 `MarketNode` 抛出 `NOT_FOUND`。
3. `IGroupBuyActivityDao` / `IGroupBuyDiscountDao` 的 Mapper SQL 没有数据库层测试。
4. `ProductRepository` 的 CRUD 和 Redis 缓存逻辑没有基础设施层测试。
5. `MarketNode` 存在异步查询后又同步查询的重复取数，折扣查询仍是同步查询。
6. `GroupBuyActivityRepository.withinTagCrowdRange()` 目前是占位实现，直接返回 `false`。
