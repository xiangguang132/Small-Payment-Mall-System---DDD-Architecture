## 下一步

### 1. 接通 `TagNode`

建议逻辑：

```java
String tagId = activity.getTagId();
String tagScope = activity.getTagScope();

if (StringUtils.isBlank(tagId)) {
    dynamicContext.setVisible(true);
    dynamicContext.setEnable(true);
} else {
    boolean within = activityRepository.withinTagCrowdRange(
            tagId,
            requestParameter.getUserId()
    );

    boolean visibleAllowed = StringUtils.isBlank(tagScope)
            || !Arrays.asList(tagScope.split(",")).contains("1");
    boolean enableAllowed = StringUtils.isBlank(tagScope)
            || !Arrays.asList(tagScope.split(",")).contains("2");

    dynamicContext.setVisible(visibleAllowed || within);
    dynamicContext.setEnable(enableAllowed || within);
}
```

含义：

- `tagScope` 为空：所有人都可见、可参与。
- `tagScope = 1`：只有命中人群的用户可见。
- `tagScope = 2`：只有命中人群的用户可参与。
- `tagScope = 1,2`：只有命中人群的用户可见且可参与。
