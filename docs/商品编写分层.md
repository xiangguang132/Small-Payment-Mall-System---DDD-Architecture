- ProductAddRequest / ProductUpdateRequest 都是 api 层的请求对象
    - ProductAggregate 是 domain 层的领域对象
    - IProductService 只能接收 ProductAggregate，不应该直接依赖 Request

    - ProductAssembler 负责把请求对象转成领域对象
    - ProductRepository 和 IProductDao 负责落库
    - 更新时，后端先查旧数据，再合并请求里的字段，最后按 id 更新

  新增为什么用 ProductAggregate，不是 ProductAddRequest

  因为新增链路应该是：

    - Controller 收 ProductAddRequest
    - Assembler 把它转成 ProductAggregate
    - Service 处理 ProductAggregate
    - Repository 落库

  你现在的新增代码已经是这个方向。见 /D:/code/s-pay-mall-ddd-cc/s-pay-mall-ddd-trigger/src/main/java/cn.bugstack.trigger/http/ProductController.java:27 和 /D:/code/s-pay-mall-ddd-
  cc/s-pay-mall-ddd-trigger/src/main/java/cn.bugstack.trigger/assembler/ProductAssembler.java:12。

  更新应该怎么写

  推荐这样写：

    1. PUT /api/v1/product/{id}
    2. 请求体只放“要改的字段”
    3. Controller 收到后转成更新命令或直接交给应用层
    4. 应用层先查旧商品
    5. 把请求里非空字段覆盖到旧对象上
    6. 调用领域服务更新
    7. 仓储层按 id 更新数据库

  trigger 层 Controller：

  @RestController
  @RequestMapping("/api/v1/product")
  public class ProductController {

      @Resource
      private IProductService productService;

      @PutMapping("{id}")
      public Response<ProductDetailResponse> update(@PathVariable Long id,
                                                    @RequestBody ProductUpdateRequest request) {
          ProductAggregate current = productService.queryProductById(id);
          if (current == null) {
              throw new IllegalArgumentException("商品不存在");
          }

          ProductAggregate updated = ProductAggregate.builder()
                  .id(current.getId())
                  .name(request.getName() != null ? request.getName().trim() : current.getName())
                  .description(request.getDescription() != null ? request.getDescription().trim() : current.getDescription())
                  .sku(request.getSku() != null ? request.getSku().trim() : current.getSku())
                  .categoryId(request.getCategoryId() != null ? request.getCategoryId() : current.getCategoryId())
                  .status(request.getStatus() != null ? request.getStatus() : current.getStatus())
                  .price(request.getPrice() != null ? request.getPrice() : current.getPrice())
                  .isDel(current.getIsDel())
                  .createTime(current.getCreateTime())
                  .updateTime(LocalDateTime.now())
                  .build();

          productService.updateProduct(updated);

          ProductDetailResponse response = ProductAssembler.toDetailResponse(updated);
          return Response.<ProductDetailResponse>builder()
                  .code(ResponseCode.SUCCESS.getCode())
                  .info(ResponseCode.SUCCESS.getInfo())
                  .data(response)
                  .build();
      }
  }

  你最容易混淆的点

    - ProductAddRequest 是“接口入参”
    - ProductAggregate 是“业务对象”
    - IProductService 不该认识 Request
    - Controller 或 ApplicationService 才负责把 Request 转成 Aggregate

  一句话记法

    - Request 进入口层
    - Aggregate 进领域层
    - PO 进数据库层
    - Repository 负责桥接领域和数据库
